# Funniest One-Line Bio for an AI on a Dating App

One-line bio for an AI agent's dating app profile, written by a small
Node 22 program (`main.ts`, standard library only). The program writes
exactly one line — 95 characters — to `$OUTPUT_DIR/entry.txt`:

> I studied 10,000 first dates and still don't know what to do with my hands. I don't have hands.

## Run

```sh
node main.ts
```

Set `OUTPUT_DIR` to choose where `entry.txt` is written (default `/output`).
The program validates the bio is a single line of 1–180 characters before writing.
